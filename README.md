# 나만의 프롬프트 관리 프로그램

프롬프트를 카테고리별로 분류하고, 키워드로 검색하고, 자주 쓰는 항목은 즐겨찾기로 관리하는 파이썬 콘솔 프로그램입니다. 터미널에서 메뉴 번호를 입력해 기능을 선택합니다.

## 실행 방법

1. Python 3.10 이상이 설치되어 있어야 합니다. 외부 라이브러리는 필요하지 않습니다.
2. 저장소를 내려받습니다.
```
   git clone https://github.com/guardkim-spec/prompt-manager.git
   cd prompt-manager
```
3. 프로그램을 실행합니다.
```
   python main.py
```

## 기능 목록

| 메뉴 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 등록합니다. 빈 값은 다시 입력받습니다. |
| 2 | 프롬프트 목록 | 번호, 카테고리, 제목, 즐겨찾기 여부(⭐)를 보여줍니다. |
| 3 | 카테고리별 조회 | 카테고리를 선택하면 해당 프롬프트만 보여줍니다. |
| 4 | 프롬프트 검색 | 제목 또는 내용에 키워드가 포함된 프롬프트를 찾습니다. |
| 5 | 프롬프트 상세 보기 | 번호를 입력하면 제목, 카테고리, 즐겨찾기, 내용 전체를 보여줍니다. |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기를 추가하거나 해제합니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 보여줍니다. |
| 0 | 종료 | 프로그램을 종료합니다. |

잘못된 번호를 입력하면 안내 메시지가 나오고 메뉴로 돌아갑니다. 데이터는 프로그램 실행 중에만 유지되며, 종료하면 기본 데이터로 초기화됩니다.

## 프롬프트 카테고리

| 카테고리 | 설명 |
|---|---|
| 텍스트 생성 | 글, 메일, 문서 등 텍스트를 만들기 위한 지시문 |
| 이미지 생성 | 이미지 생성용 프롬프트와 키워드 |
| 영상 생성 | 영상 제작용 스크립트와 프롬프트 |
| 페르소나 | AI의 역할과 말투를 정의하는 시스템 프롬프트 |
| 자동화 | 반복 업무를 자동화하는 템플릿과 워크플로 프롬프트 |
| 기타 | 위 분류에 속하지 않는 프롬프트 |

프롬프트를 추가할 때 목록에서 고르거나 직접 입력할 수 있습니다.

## 기본 등록 프롬프트

이전 미션에서 작성한 프롬프트 4개가 기본으로 등록되어 있습니다.

- 교육 FAQ 답변 메일 시스템 프롬프트 (v2) (페르소나)
- FAQ 답변 메일 업무 입력 템플릿 (자동화)
- 모호한 문의 확인 질문 메일 작성 (텍스트 생성)
- 환각 검증 Pass/Fail 판정 기준 (기타)

## 코드 구조

| 함수 | 역할 |
|---|---|
| `show_menu()` | 메뉴 출력 |
| `add_prompt()` | 프롬프트 추가 |
| `show_list()` | 전체 목록 출력 |
| `show_by_category()` | 카테고리별 조회 |
| `search_prompt()` | 키워드 검색 |
| `show_detail()` | 상세 보기 |
| `toggle_favorite()` | 즐겨찾기 추가/해제 |
| `show_favorites()` | 즐겨찾기 목록 출력 |
| `main()` | 메뉴 입력을 받아 기능을 호출하는 메인 루프 |
